# nootifications

**01.2026 Update:** this bot is outdated and only kept here for posterity; it also had credentials stored in plaintext 🫠 *(I was young and didn't know any better)*

track crypto prices and send notifications via telegram

service installation process:
1. create: `sudo cp ./nootifications.service /etc/systemd/system/`
2. enable: `systemctl enable nootifications.service`
3. run: `systemctl start nootifications.service`
